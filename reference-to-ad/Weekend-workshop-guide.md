# From reference to ad: weekend workshop

This workshop uses the Reelix headphone film as a case study. The goal is to leave with an original, reviewable treatment and first-shot plan for **your own** product, service or place. The Reelix production prompts are examples, not one-click templates.

## 60-minute teaching plan

| Time | Show | Learners do |
|---|---|---|
| 0–7 min | The 36-second ad, then the first part of the explainer | Say what they notice before hearing the process |
| 7–17 min | Source DNA: camera, pace, texture, background life, the historical-modern joke | Pick 3 things to carry over and 2 things to change |
| 17–27 min | The giant-headphone premise and the shot list | Write a one-sentence product idea and a 5–7 shot sequence |
| 27–39 min | Approved character, location and prop sheets | Assign one job to each reference; draw a single location master |
| 39–49 min | Prompt UI: spoken feedback → measurable correction | Rewrite “it looks wrong” into one precise, testable change |
| 49–56 min | Storyboard, first motion test, camera join, picture-first sound | Decide which shots need start/end stills and which need only action prompts |
| 56–60 min | Finished edit and credit list | Name one review gate and one original source to credit |

## Participant worksheet

**Reference URL / creator:**

**What I am actually borrowing:** look / camera / pace / editing / texture / world behavior

**What I will deliberately change:** story / product / person / place / joke / payoff

**The ad in one sentence:**

**Audience and action:** who watches, and what should they do next?

**Source DNA evidence:** choose at least three specific timestamps or frames. For each, note the camera angle, visible action, light, texture and background activity. Do not rely on a vibe label alone.

**Asset map:**

| Role | My approved source | What it controls | What it must not control |
|---|---|---|---|
| Identity | | face and proportions | wardrobe or pose |
| Wardrobe | | clothing and materials | facial identity |
| Location master | | geography, entrances, light | hero action |
| Prop | | design, color, physical scale | location or person |
| DNA frame | | camera/texture/pacing | copying the original cast/story |

**Shot list:** For each shot, write location, camera, subject action, background action, key prop, intended duration, and connection to the next shot. Show this list before generating storyboards.

**Storyboard decision:** Which movement needs a start frame? Which needs an end frame? When does a previous shot genuinely help continuity, and when should a new location master take over?

**Director feedback → prompt correction:**

1. What looked wrong?
2. Which authority image already has the right answer?
3. What single visible relationship can the model change?
4. What parts of the approved shot must stay locked?
5. How will you tell whether the next result passed?

**Edit and sound:** Complete all approved stills first. Generate one motion test, then review pace, identity, object scale, background life and camera continuity. Lock picture before making music. Let sound change when the story changes, then add grain and effects. Credit the original inspiration in the video description and lesson page.

## Demo prompt to build together

> Make one photorealistic 16:9 wide master of [place] from a three-quarter corner. The setting combines [historical/real-world source] with [modern function] in a believable way. The camera sees [entrance], [main action zone], and [background work zone] in one coherent geography. Keep [walking/riding/handling route] physically usable. Light comes from [direction] and keeps [source texture]. No hero action yet. Use reference A for architecture only, B for light and texture only, and C for the product's color and construction only. Acceptance: [three visible criteria].

Before anyone generates, replace all brackets, use references they have rights to use, and approve the shot list and asset roles. For multi-shot locations, use the approved master to create later camera angles only when the story needs them.
